# Microstock Keyworder Metadata Generator

Official desktop installers and signed update packages.

Download the newest installer from [Releases](https://github.com/felopes128/microstock-keyworder-releases/releases). Source code is maintained in a separate private repository. This repository contains distribution files only.

The installed app checks for updates automatically. When a new version is available, choose **Install update** to download it, verify its signature, and restart. Updates wait until generation, importing, and file exports are idle.

Development previews may be unsigned at the operating-system level. Tauri updater signatures and Windows/macOS publisher signing are separate. See each release's notes for platform availability and known limitations.

Website: [Microstock Keyworder](https://microstockkeyworder.com/)
